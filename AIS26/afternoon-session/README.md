# AIS26 Afternoon Session

AI Summit Seoul 2026 오후 세션 중 전하께서 실제로 들어간 세션을 정리하는 폴더입니다.

오전 세션 자료와 섞이지 않도록 전하 참석 세션의 실시간 통역본, 10분 단위 조각 파일, 세션별 요약본을 이 폴더에 따로 저장합니다.

오후 전체 세션을 정리하는 공간은 [`../afternoon-session-all/`](../afternoon-session-all/)에 따로 둡니다.

## Tracks

전하 참석 오후 세션은 4개 트랙 중 실제 이동한 트랙을 기준으로 관리합니다.

전하 참석 예정 트랙 순서: A -> A -> D -> B -> B -> B -> B

전하 참석 기준 오후 세션은 30분씩 총 7개 세션으로 관리합니다. 상세 시간표는 [`selected-tracks.md`](./selected-tracks.md)를 확인하면 됩니다.

| 트랙 | 폴더 | 설명 |
| --- | --- | --- |
| A | [`tracks/A/`](./tracks/A/) | 참석 예정 2개 세션, 1-2차 세션 요약 완료 |
| B | [`tracks/B/`](./tracks/B/) | 참석 예정 4개 세션 |
| C | [`tracks/C/`](./tracks/C/) | 참석 예정 없음 |
| D | [`tracks/D/`](./tracks/D/) | 참석 예정 1개 세션, 3차 세션 요약 완료 |

## Notes

- 기준 시간: 2026-08-19 13:00 KST 이후
- 자동 푸시 주기: 10분
- 이후 오후 세션 요약본도 이 폴더 안에 추가할 예정입니다.
- 전하께서 참석한 세션은 `selected-tracks.md` 순서에 맞춰 해당 트랙 폴더에 별도로 정리할 예정입니다.
