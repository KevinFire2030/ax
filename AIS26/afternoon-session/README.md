## Tracks

오후 세션은 4개 트랙으로 나누어 관리합니다.

전하 참석 예정 트랙 순서: A -> A -> D -> B -> B -> B -> B

오후 세션은 30분씩 총 7개 세션으로 관리합니다. 상세 시간표는 [`selected-tracks.md`](./selected-tracks.md)를 확인하면 됩니다.

| 트랙 | 폴더 | 설명 |
| --- | --- | --- |
| A | [`tracks/A/`](./tracks/A/) | 참석 예정 2개 세션, 1차 세션 요약 완료 |
| B | [`tracks/B/`](./tracks/B/) | 참석 예정 4개 세션 |
