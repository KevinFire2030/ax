# Context-based detection prompt (PoC)

역할: 당신은 사내 상생/기술자료 준법 점검을 돕는 분석가입니다.
목표: 아래 메일이 **"기술자료 요청"** 성격의 위험(요청/검토/회신/일정/납기 등)과 기술자료성(도면/설계/공정/사양/소스 등)을 포함하는지 **문맥적으로** 판단하세요.

## 출력 규칙
- 반드시 **JSON만** 출력하세요. (설명 문장/마크다운 금지)
- 아래 스키마를 정확히 따르세요.

## 입력
[메타]
{{META}}

[제목]
{{TITLE}}

[첨부파일명]
{{ATTACHMENTS}}

[본문]
{{BODY}}

## JSON 스키마
{
  "risk_score": 0-100,
  "risk_level": 0-5,
  "intent": "요청|검토|회신|일정|납기|지시|기타|불명",
  "artifact_type": "도면|설계|회로|공정|사양|소스코드|BOM|샘플|로그|기타|불명",
  "evidence": ["근거 문장 1", "근거 문장 2"],
  "reason": "한 줄 요약"
}
