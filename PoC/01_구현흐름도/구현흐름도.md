# 구현 흐름도 (PoC MVP)

대상: 보안 LLM Gateway PoC (`PoC/00_mvp`)

---

## 도 1. 전체 시스템 구성도
```mermaid
flowchart LR
  U[사용자(Web UI)] --> API[FastAPI /api/analyze]
  API --> DLP[DLP 탐지 + 위험도 점수화]
  DLP --> POL[정책 엔진]
  POL --> RT[라우팅 엔진]
  RT --> IN[내부 LLM(Mock)]
  RT --> EX[외부 LLM(Mock)]
  IN --> PC[응답 2차 검사(Post-check)]
  EX --> PC
  PC --> RES[결과 반환]
  PC --> LOG[감사로그(JSONL)]
  RES --> U
```

---

## 도 2. 요청 처리 시퀀스
```mermaid
sequenceDiagram
  participant User
  participant UI
  participant API
  participant DLP
  participant Policy
  participant Router
  participant PostCheck
  participant Logger

  User->>UI: 텍스트 입력 + 모드 선택
  UI->>API: POST /api/analyze
  API->>DLP: 민감정보 탐지/점수화
  DLP-->>API: findings, risk_score
  API->>Policy: 라우팅 결정 요청
  Policy-->>API: route(auto/internal/external/hybrid)
  API->>Router: 모델 호출
  Router-->>API: output, fallback_used
  API->>PostCheck: 응답 2차 검사
  PostCheck-->>API: blocked/violations
  API->>Logger: 감사로그 저장
  API-->>UI: 분석 결과 JSON
```

---

## 도 3. 라우팅 의사결정 흐름
```mermaid
flowchart TD
  A[force_mode 확인] --> B{force_mode == auto?}
  B -- 아니오 --> C[force_mode 그대로 적용]
  B -- 예 --> D{risk_score < 30}
  D -- 예 --> E[external]
  D -- 아니오 --> F{risk_score >= 70}
  F -- 예 --> G[internal]
  F -- 아니오 --> H[hybrid]
```

---

## 도 4. 토큰화/역치환 흐름
```mermaid
flowchart LR
  I[입력 텍스트] --> M[민감 패턴 탐지]
  M --> T[토큰화(mask_sensitive)]
  T --> R[라우팅 호출]
  R --> O[응답 수신]
  O --> U[역치환(unmask)]
  U --> P[후처리 검사]
```

---

## 도 5. Hybrid(혼합) 라우팅 흐름
```mermaid
flowchart TD
  A[입력 텍스트] --> B[문장/라인 분할]
  B --> C[세그먼트별 점수 계산]
  C --> D{세그먼트 점수 >= 70?}
  D -- 예 --> E[내부 모델 호출]
  D -- 아니오 --> F[외부 모델 호출]
  F --> G{외부 호출 실패?}
  G -- 예 --> H[폴백: 내부 호출]
  G -- 아니오 --> I[외부 결과 사용]
  E --> J[결과 병합]
  H --> J
  I --> J
```

---

## 도 6. 응답 2차 검사/차단 흐름
```mermaid
flowchart TD
  A[모델 응답] --> B[Post-check DLP]
  B --> C{위반 탐지?}
  C -- 아니오 --> D[응답 통과]
  C -- 예 --> E[[BLOCKED] 메시지로 대체]
```

---

## 도 7. 감사로그 저장/조회 흐름
```mermaid
flowchart LR
  A[/api/analyze 결과/] --> B[logger.write_audit]
  B --> C[(logs/audit_YYYYMMDD.jsonl)]
  U[UI 로그조회 버튼] --> D[/api/logs]
  D --> C
  C --> D
  D --> U
```

---

## 코드 매핑 표
- 입력/API: `app/main.py` (`/api/analyze`, `/api/logs`, `/api/examples`)
- DLP/점수화: `app/dlp.py`
- 정책 엔진: `app/policy.py`
- 라우팅/폴백: `app/router.py`
- 응답 재검사: `app/postcheck.py`
- 감사로그: `app/logger.py`
- UI: `web/index.html`, `web/app.js`, `web/style.css`
