# 미팅용 1장 슬라이드 문안

## 슬라이드 제목
선행특허 대비 차별성 요약 – 보안 LLM 게이트웨이

---

## 1) 선행특허 검토 결과 (요약)
- 비식별/가명화/토큰화 자체 기술은 다수 존재
- 재식별 방지/프라이버시 보호 관련 개별 기술도 확인
- 그러나 “LLM 라우팅 운영 제어”까지 일체화한 구조는 제한적

## 2) 충돌 가능 영역 (주의)
- 비식별 처리 자체
- 토큰/매핑키 기반 치환 자체

## 3) 당사 핵심 차별 포인트 (권리화 중심)
- 위험도 점수 기반 내부/외부 LLM 동적 라우팅
- 프롬프트 세그먼트 단위 하이브리드 라우팅
- 응답 단계 2차 DLP 재검사(출력 통제)
- 정책 엔진 기반 통제(권한/등급/업무/시간/모델정책)
- 라우팅 사유/정책버전/차단사유 감사로그

## 4) 청구항 전략
- 독립항: “점수화 + 동적 라우팅 + 응답 재검사” 결합 구조
- 종속항: 토큰화/역치환, 세그먼트 라우팅, 폴백, 감사로그

## 5) 결론
- 단순 비식별 특허가 아니라,
  보안-성능 동시 최적화형 LLM 제어 게이트웨이로 포지셔닝 시 승산 높음
